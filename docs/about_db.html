Sentinel K8s Database Documentation

1. Overview

Sentinel K8s uses MySQL 8 as its persistent data store, running inside a Docker container and exposed on port 3008. The sentinel_k8s database contains 4 tables:

  • k8s_events — Kubernetes events, admission reviews, and alerts
  • app_config — Application configuration (LLM credentials, settings)
  • users — User accounts with bcrypt-hashed passwords and TOTP secrets
  • sessions — Persistent auth sessions with TTL expiration

5. Column Reference

event_id — Generation

Generated in webhook_receiver.py using SHA256 hash, truncated to 16 hex characters:

event_id = hashlib.sha256(
    f"{kind}:{namespace}:{name}:{reason}:{message}:{now}".encode()
).hexdigest()[:16]

The timestamp in the hash ensures uniqueness even for identical events at different times.

raw_payload — JSON Storage

Stores the full incoming JSON payload as a string via json.dumps(payload). When read back, it is parsed with json.loads() for display. Uses LONGTEXT to accommodate large admission review payloads.

created_at / updated_at — Timestamps

Stored as ISO 8601 strings in UTC: 2026-03-03T10:42:40.292441+00:00. Generated via datetime.now(timezone.utc).isoformat().

8e. Authentication Flow

Two-step login: password verification (bcrypt) followed by TOTP verification. Sessions are persisted in the sessions table with TTL expiration.

Frontend
Login Form
→ POST /api/auth/login
auth.py
login()
↓ SELECT * FROM users WHERE username = %s
Step 1: Password Verification
1. Fetch user from users table by username
2. Verify password with bcrypt.checkpw() against password_hash
3. Check if totp_secret is set (first-time setup vs returning user)
4. Generate temp token → INSERT INTO sessions (is_temp=TRUE, TTL=5min)
5. If first-time: generate TOTP secret, QR code, return in response
↓ Return temp_token + QR (if setup)
Frontend
TOTP Input
→ POST /api/auth/verify-totp
auth.py
verify_totp()
↓ Validate temp session + TOTP code
Step 2: TOTP Verification
1. SELECT * FROM sessions WHERE token = %s AND is_temp = TRUE AND expires_at > NOW()
2. Get user's TOTP secret from users table (or pending secret for first-time)
3. Verify code with pyotp.TOTP.verify(code, valid_window=1)
4. First-time setup: UPDATE users SET totp_secret = %s
5. Delete temp session → DELETE FROM sessions WHERE token = %s
6. Create full session → INSERT INTO sessions (is_temp=FALSE, TTL=24h)
↓ Return auth token (24h)

Stores token in localStorage
→ Authorization: Bearer {token}
require_auth()
Every protected endpoint
↓ SELECT * FROM sessions WHERE token = %s AND is_temp = FALSE AND expires_at > NOW()
Access Granted
Request proceeds to handler

Session Cleanup

A background task in main.py runs DELETE FROM sessions WHERE expires_at < NOW() every 60 seconds, removing expired temp tokens and full sessions.

10. Security Architecture

All application secrets are stored in MySQL — nothing sensitive lives in environment variables, flat files, or application memory.

Security Migration Summary

SecretBefore (Insecure)After (Secure)
User passwords Plaintext in .env + env vars, compared with == bcrypt hash in users.password_hash, verified with bcrypt.checkpw()
TOTP secrets Flat file .totp_secret (lost on container rebuild) Database users.totp_secret column (persistent)
Session tokens In-memory Python set() (lost on restart, no expiration) Database sessions table with TTL expiration
LLM credentials Env vars in .env, docker-compose.yml Database app_config table (changeable at runtime)
Temp tokens In-memory Python dict() (no TTL) Database sessions table with 5-min TTL

Password Hashing

# Hashing (on seed / password change):
hashed = bcrypt.hashpw(password.encode(), bcrypt.gensalt()).decode()
# Stored: "$2b$12$JCVJLVEq2B96UrjhM4DhNe..." (60 chars)

# Verification (on login):
bcrypt.checkpw(req.password.encode(), user["password_hash"].encode())
# Returns True/False — constant-time comparison, resistant to timing attacks

conn = get_db()            # Get pooled connection

13. Initialization Script — init.sql

Mounted into the MySQL container at /docker-entrypoint-initdb.d/init.sql. Runs automatically on first container creation only. The init_db() function in database.py also creates these tables on every startup (idempotent).

-- MySQL initialization script for Sentinel K8s

CREATE DATABASE IF NOT EXISTS sentinel_k8s;

CREATE USER IF NOT EXISTS 'sentinel'@'%' IDENTIFIED BY 'sentinel_pass';
GRANT ALL PRIVILEGES ON sentinel_k8s.* TO 'sentinel'@'%';
FLUSH PRIVILEGES;

USE sentinel_k8s;

CREATE TABLE IF NOT EXISTS k8s_events (
    id          INT AUTO_INCREMENT PRIMARY KEY,
    event_id    VARCHAR(64) NOT NULL UNIQUE,
    event_type  VARCHAR(32) NOT NULL,
    kind        VARCHAR(64),
    name        VARCHAR(253),
    namespace   VARCHAR(253),
    reason      VARCHAR(128),
    message     TEXT,
    severity    VARCHAR(16) DEFAULT 'info',
    raw_payload LONGTEXT NOT NULL,
    status      VARCHAR(16) DEFAULT 'new',
    analysis    TEXT,
    created_at  VARCHAR(64) NOT NULL,
    updated_at  VARCHAR(64) NOT NULL
);

CREATE INDEX idx_status ON k8s_events(status);
CREATE INDEX idx_severity ON k8s_events(severity);
CREATE INDEX idx_created ON k8s_events(created_at);

-- Application configuration (LLM credentials, etc.)
CREATE TABLE IF NOT EXISTS app_config (
    config_key   VARCHAR(128) PRIMARY KEY,
    config_value TEXT NOT NULL,
    updated_at   TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

-- User accounts with bcrypt-hashed passwords and TOTP secrets
CREATE TABLE IF NOT EXISTS users (
    id            INT AUTO_INCREMENT PRIMARY KEY,
    username      VARCHAR(128) NOT NULL UNIQUE,
    password_hash VARCHAR(256) NOT NULL,
    totp_secret   VARCHAR(64),
    created_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Persistent sessions with TTL expiration
CREATE TABLE IF NOT EXISTS sessions (
    token      VARCHAR(128) PRIMARY KEY,
    username   VARCHAR(128) NOT NULL,
    is_temp    BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    expires_at TIMESTAMP NOT NULL,
    INDEX idx_expires (expires_at)
);

FROM k8s_events WHERE status = 'analyzed';

# Check table size
SELECT COUNT(*) AS total_events,
       ROUND(SUM(LENGTH(raw_payload))/1024/1024, 2) AS payload_mb
FROM k8s_events;

User & Auth Queries

# View users (password hash truncated for display)
SELECT id, username, LEFT(password_hash, 30) AS hash_preview,
       totp_secret IS NOT NULL AS has_2fa, created_at
FROM users;

# View active sessions
SELECT LEFT(token, 20) AS token_preview, username, is_temp,
       created_at, expires_at,
       TIMESTAMPDIFF(MINUTE, NOW(), expires_at) AS minutes_remaining
FROM sessions WHERE expires_at > NOW();

# Count sessions by type
SELECT IF(is_temp, 'temp', 'full') AS type, COUNT(*) AS count
FROM sessions WHERE expires_at > NOW() GROUP BY is_temp;

# Manually expire all sessions (force re-login)
UPDATE sessions SET expires_at = NOW();

# Reset admin password (generate bcrypt hash externally first)
# python3 -c "import bcrypt; print(bcrypt.hashpw(b'newpass', bcrypt.gensalt()).decode())"
UPDATE users SET password_hash = '$2b$12$...' WHERE username = 'admin';

# Reset TOTP (forces QR code re-setup on next login)
UPDATE users SET totp_secret = NULL WHERE username = 'admin';
